#### Written Rationale for Equivalent Mutants:
- **`M18` Rationale**: In `isCliEntry`, when `if (!argv1) return false` is removed, passing `argv1: null` or `argv1: undefined` causes `path.resolve(argv1)` to throw a `TypeError: The "paths[0]" argument must be of type string. Received null`. This error is caught by the surrounding `try...catch` block in `isCliEntry`, returning `false`. When `argv1: ""` (empty string), `resolve("")` returns `process.cwd()`. The current working directory is not equal to `check-curriculum.mjs`, and its basename is not `check-curriculum.mjs`. Thus `invokedRaw === targetRaw` is false, and `basename(invokedRaw) === basename(targetRaw)` is false. As a result, all assertions pass identically under Node.js runtime path semantics.
- **`M20` Rationale**: Dropping `:?` leaves `TODO` as the token in `PROSE_UPPERCASE_TOKENS_REGEX`. When testing `containsProsePlaceholder("TODO:")`, `TODO` matches because the right lookahead `(?![\p{L}\p{N}])` permits `:` as a non-alphanumeric boundary. Both `TODO` and `TODO:` continue to match identically across all test inputs.
